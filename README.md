# 👋 About — who I am

I'm an **Electronics & Communication Engineer** focused on building practical systems at the intersection of:

> **Firmware + Hardware + Communication + IoT + Security**

I enjoy working close to the hardware — writing firmware, configuring peripherals, debugging microcontrollers, integrating sensors, designing communication interfaces, and connecting embedded devices to real-world applications.

My primary focus is **Embedded Systems and Firmware Development**, with growing interests in **Embedded Linux, FreeRTOS, FPGA, Embedded Security, IoT and Edge AI**.

### ⚡ What I enjoy building

- 🔧 Embedded firmware for microcontrollers
- 🧠 Real-time embedded applications
- 🌐 IoT-connected devices
- 🔐 Secure firmware and OTA systems
- 📡 Hardware communication interfaces
- ⚡ FPGA-based hardware acceleration
- 🐧 Embedded Linux systems
- 🔌 Hardware-software integrated systems
