# 👨‍💻 About Me

I'm an **Electronics & Communication Engineer** focused on **Embedded Systems, Firmware Development, IoT, Embedded Security, FPGA, and Hardware-Software Integration**.

I enjoy working close to the hardware and developing practical systems that connect:

**Microcontrollers → Firmware → Hardware → Communication → Networking → Cloud → Applications**

My primary interests include building reliable embedded firmware, developing communication interfaces, designing bootloader and OTA systems, integrating hardware with software, and exploring real-time embedded architectures.

### 🚀 Current Engineering Interests

- 🔧 Embedded Firmware Development

- ⚡ Real-Time Embedded Systems
